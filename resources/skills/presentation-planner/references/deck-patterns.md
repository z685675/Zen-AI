# Deck Patterns

Use this reference to choose the storyline before generating slide content.

## Leadership Report

Flow: conclusion first -> current state -> evidence -> decision -> next actions.

Best layouts:
- Cover
- Agenda
- Metric
- Insight
- Comparison
- Process
- Summary

Use when the audience is busy and expects the recommendation quickly.

## Product Proposal

Flow: user pain -> opportunity -> solution -> scope -> roadmap -> risks -> asks.

Best layouts:
- Cover
- Insight
- Cards
- Process
- Comparison
- Summary

Use when the deck must align product, design, engineering, and business stakeholders.

## Investor Or Sales Pitch

Flow: market pain -> product value -> proof -> differentiation -> plan -> ask.

Best layouts:
- Cover
- Metric
- Cards
- Comparison
- Process
- Summary

Use proof slides early; do not wait until the end to show traction or credibility.

## Training Or Courseware

Flow: learning goal -> concept -> example -> practice -> recap.

Best layouts:
- Cover
- Agenda
- Section
- Insight
- Cards
- Process
- Summary

Use section dividers and examples to prevent the deck from becoming a manual.

## Slide Title Rules

- Weak: "Background"; stronger: "用户需要一个不会打断工作的自动化入口".
- Weak: "Analysis"; stronger: "先做个人场景能更快验证留存价值".
- Weak: "Next steps"; stronger: "下一阶段重点是打通提醒、执行和复盘".
