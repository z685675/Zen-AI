# Chinese Content Platform Patterns

Use this reference when adapting Chinese copy for a specific channel.

## WeChat Article

- Opening: present a concrete tension, question, or scene.
- Body: use clear subheadings and examples.
- Style: calm, useful, credible.
- Ending: leave a concrete takeaway or next action.

Avoid: long slogans, empty industry language, and paragraphs that feel translated.

## Xiaohongshu

- Opening: direct scene or benefit within the first line.
- Body: short paragraphs, practical bullets, personal angle when appropriate.
- Style: conversational and specific.
- Ending: invite save/comment/follow only when natural.

Avoid: over-polished corporate tone.

## Short Video Script

- 0-3s: hook.
- 3-15s: conflict or value.
- Middle: 2-4 scene beats.
- End: memory point or action.

Include visual instructions when the user asks for an actual script.

## Product Copy

- Pain point
- Product value
- Proof
- Objection handling
- Call to action

Specific proof beats adjectives. Run `scripts/check_cn_copy.py` for important marketing drafts.
