# 新版助手：Office 质量与工具失败指引

日期：2026-10-12。开发预览仍为 1.1.71，OpenCode 固定 1.18.35。本批只做 Office 输出质量、工具失败指引；会话成果中心和缓存成本诊断暂未实施。

## 1. 实际补齐

### Excel

- 新版 `create_file` 的公式必须带显式结果，缺失、null、非有限数会在写入前失败，不再拿 value 或 0 冒充计算结果。合法的 0、false、空字符串不会误判为缺失。
- 保留已有循环引用、外部公式、简单 SUMIF/SUMIFS 缓存核对；不声称所有公式经过完整 Excel 重算。
- 新增 decimal、currency、date 单元格格式，保持底层数字可计算。currency 为分组两位小数，货币单位放列名，不猜人民币/美元。date 使用 Excel 1900 日期系统的数值序列，不接收预格式化日期文字；不做含混日期推断或时区转换。
- 新版超过每表 4 个图表时明确报错，不悄悄截掉剩余图表。

### Word

- 新版默认启用段落孤行控制，沿用原生标题与后文保持相邻、重复表头、单元格留白设置。
- 保留表头不可拆分，正文表格行允许 Word/LibreOffice 在需要时跨页，避免长行被强制整体推移。短行是否落在页底，由实际排版引擎决定；不声称精确预知每一页。
- Markdown 表格、显式 rows 均接入，不重复追加源内容，不改变品牌风格或默认页面尺寸。

### PPT

- 新版普通/自适应生成在写文件前检查对应页正文的文本覆盖；备注、设计指示、其他页的文字不算该页可见内容。布局可将标题/明细拆成多个形状。
- 引言页沿用原设计：有实际引言时，页标题可作为非显示元信息。部分布局只展示 subtitle/takeaway 中一项，检查其实际选用的说明，不强迫两个都显示。
- 检出正文条目遗漏，提示具体页与字段，要求分续页或换合适布局，不静默截断、不原样重复请求。Markdown 自动分页超过 30 页时也明确失败；可用显式 slides 或分文稿。
- 修复被代表样例证实的内容遗漏：bold/brand 封面标签，部分时间线阶段标记，route 的站点阶段名，bold/brand/playful/organic 总结页说明。保持原生形状、权限与生成路径。
- 原生模板 edit-copy/new-deck 沿用其映射验证，不套普通生成的文本检查。
- 此检查不是语义审核、排版截图审核、逐项重复次数证明或事实校验。图片页注释容量可能因风格而异；超容量需分成续页。

## 2. 工具失败如何显示

产品 MCP 工具只在新版返回有版本的失败结构，原生 OpenCode 保留其错误事件；前端在工具折叠区外展示简短原因、下一步和默认收起的技术详情，切换会话后仍可显示。

按实际错误区分：停止、权限、缺文件、已有/占用/变化文件、Python 依赖、本地环境、输出检查、参数/格式、限流、超时、网络、未知。没有可靠证据时显示未知，不用字符串猜测模型是否被禁用或整条网络链路根因。

技术详情限制长度并脱敏凭据；新版 Python 失败时的 stdout/stderr 也限制长度，避免长堆栈把整条失败结构撑大而无法显示指引。成功时保留正常输出。非结构化的原生工具/第三方 MCP 错误仍沿用原展示，不冒称所有错误已精确分类。Python 非零退出同时记为失败，避免性能诊断误标成功。

指引不授予安装、绕过权限或重放动作的授权。本批没有增加产品层自动重试、另一套任务循环、审核模型或重放机制；OpenCode 原生的推理与纠正机制继续保留。自动修改已有文件、下载/提交重复执行的安全仍由原有权限及操作边界约束，并非新增的完整事务系统。

## 3. 生效与边界

- 仅新版入口使用严格生成检查和失败结构。弃用助手保持只读，旧微信/定时/心跳保持关闭。模型政策、Provider、API 路由、原生压缩、数据库与 Redux 状态结构不变。
- 不更改版本号、提交或推送，也不升级内核或自动安装依赖。
- Office Skill 只加少量与实际缺口相关的规则，详细数字格式放按需参考。生成器和工具 schema 的改动重启开发程序即可生效。
- 已安装/工作区复制的 Skill 按现有版本和复制机制更新；同版本 pnpm dev 不保证旧副本自动刷新。可用 skill_status 查看实际来源。不得为测试覆盖用户自行维护的技能；新发版后仍需核对来源及内容。
- 结构检查通过不等于视觉、业务数据或真实模型都已验收。复用原有 Office 渲染器；不可用时如实说明，不启动环境安装。
