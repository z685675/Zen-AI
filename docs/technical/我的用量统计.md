# 我的用量

## 页面

- 左侧入口位于“旧助手”下方；顶部导航模式可从启动台进入。
- 默认本月。支持今日、本周、近 7 天、近 30 天和自选日期，单次最多 366 个自然日。
- 总览：输入、输出、缓存、缓存命中率。
- 趋势支持按日、周、月聚合；周一为一周起点。
- 趋势悬浮提示覆盖日期整列，立即显示该日期的输入、输出和缓存精确值；按周／月显示当前筛选范围内的实际起止日期及合计。支持键盘聚焦或点击查看，离开后关闭；未知缓存不伪装成零，部分缓存显示已知下限。
- 模型表格支持搜索、用量排序和分页。
- 场景：全部、AI 对话、智能助手。三种助手来源合并统计，不干预任务执行。
- 不展示管理员成本、渠道、对话原文或用户要求去掉的技术性来源说明。

## 后台接口与统计口径

`GET /api/usage/token/statistics`

参数：`start_timestamp`、`end_timestamp`（含首尾，秒）、`timezone`（IANA 时区）、`scene=all|chat|assistant`。

认证：Provider 现有的 API Key。只读认证允许查询已过期、额度耗尽或已停用密钥的历史；封禁账户仍拒绝。所有权由认证上下文确定，忽略传入的用户／密钥编号，不开放管理员接口。

只汇总消费日志；不把错误、退款或任务分组摘要当作另一笔 Token 用量。智能助手包括 OpenCode、Codex、Claude Client 的每一条实际调用；AI 对话采用现有 `web` 来源分类；全部保留其他来源。

复用后台现有的 Token 展示归一化规则：

- 输入含缓存。例如输入 130,000、缓存 120,000，仍显示输入 130,000。
- 总 Token = 输入 + 输出，不再加缓存。
- 缓存数沿用用量日志口径，包括缓存读取和写入；缓存命中率仅使用读取数 ÷ 输入数，不把写入视为命中。
- 历史记录未保存缓存数据时为未知，不捏造为零；部分记录可用时显示已知缓存下限，不展示不完整的命中率。

按认证用户和密钥、日期、场景查询，使用日志 ID 快照和有界批次，不加载原文。单次最多 100,000 条记录和 2,000 个模型，超限要求缩短范围，绝不静默截断。查询最多 12 秒，客户端最多等待 15 秒，响应禁止缓存。

客户端只在进入、改变筛选和手动刷新时请求，不高频轮询，不发送模型生成请求。切换服务、密钥或筛选会取消旧请求，旧结果即使稍后返回也不能覆盖新结果。统计失败不影响聊天和助手。

## 上线与检查

API 面板和 Zen AI 都需要使用本次代码。若服务器尚未更新，页面提示服务暂不支持查询，而不是展示零用量。已有历史无需迁移数据库；可查询保留在服务端、属于当前密钥的记录。

1. 启动更新后的 API 面板和 `pnpm dev`，打开旧助手下方“我的用量”。
2. 用已有历史密钥查看本月、近 30 天和过去日期，与后台相同范围的日志核对输入、输出和缓存。
3. 切换 AI 对话／智能助手，确认助手一次回答产生的多条调用均计入。
4. 搜索模型，按输入／输出／缓存排序，切换趋势按日／周／月。
5. 快速切换不同服务或日期，再刷新，确认不会串入前一次结果。
6. 测试无 Provider、无记录、无效密钥、旧服务器和暂时断网，确保提示与真正的零用量不同，且仍可切回聊天。
7. 验证多密钥只查看当前所选密钥，页面和请求 URL 不出现密钥内容。

不修改计费、渠道路由、OpenCode 循环、上下文整理、Redux 结构或本地数据库结构。
