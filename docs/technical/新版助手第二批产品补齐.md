# 新版助手第二批产品补齐

日期：2026-10-12。范围：OpenCode 新版助手，当前开发代码 1.1.71；不代表安装包已经包含本批改动。

## 1. 联网搜索与资料整理

- 在现有本地 assistant MCP 中新增 `web_search`；启动、工具发现和普通问答不连接外部搜索服务。
- 按需使用 Exa 公共 MCP 的 `web_search_exa`，不携带 Provider Key、不继承搜索账号，不自动升级到付费服务。只发送模型提交的搜索词和结果数量，不自动附加历史或文件。
- 第三方可能保存查询、用于训练并收集网络信息。搜索词不得包含个人信息、密钥或私密文件内容；新版会话基础设置展示说明。
- 标准 MCP 初始化与 JSON/SSE 解析交由现有 SDK 处理，不复制旧简化接口。搜索来源解析保留标题、URL、发布日期与摘要；无法可靠解析时明确标记为未结构化摘录，不编造日期或链接。
- 单次整体上限20秒，含初始化和响应读取；支持停止，最多同时2次，每次1～8项结果，响应最多2MiB，返回摘录有长度上限。
- 429 尊重 Retry-After 并实施最长5分钟的本地搜索冷却，不循环自动请求。其他故障只影响搜索工具；模型可使用既有浏览器查看原网页或说明局限。
- 搜索摘要不是完整原文证据。需要核实的事实与日期应打开相关原网页；用户给了具体链接时仍可以直接用浏览器，不强制先搜索。
- 公共入口无永久免费、固定额度或可用性保证。产品未接入账号搜索配置或后台搜索调度。

## 2. Skill 兼容与状态说明

- 全局技能详情增加“兼容检查”，用户点击后才执行，只读，不运行第三方脚本、不安装依赖。
- 检查定义可读性、原生必要字段、声明的兼容条件、工具、命令、可替代命令组、环境变量名称，以及已启用全局/内置的同名候选。
- PATH 检查只确认命令文件存在及权限，不执行命令。环境变量只报告名称与是否存在，绝不输出值。
- 未声明不等于没有依赖；Python包、外部MCP/账号、脚本安全与实际任务效果仍待验证。工具名称声明不会自动建立工具连接。
- `skill_status` 在当前任务中查询原生 `/skill` 清单，只返回名字、描述和实际定义路径，不输出全部技能正文。同名胜出位置以原生结果为准，不建立第二套技能选择器。
- 已安装、已启用、原生已发现、本轮实际使用是不同状态。检查界面不把已启用当作“完美兼容/已应用”。
- 第三方导入不得覆盖注册为内置的技能目录；不同目录但同名的定义须查看冲突说明与原生实际路径，必要时停用或重命名。
- 安装/卸载技能文件使用本地生命周期互斥：已有新版任务运行时不变更技能文件，更新期间不启动新任务。启停只标记原生清单需要刷新，不中断当前任务；下一次用户发起任务时重新准备原生实例并复用持久历史，不自动执行或重放任务。
- 沿用已有数据库和全局技能导入能力，不增加数据库字段或Redux状态。

## 3. 已有文件修改安全

- 2026-10-15 更新：新版 `create_file` 和 OCR 文本输出默认另存；遇到重名自动加 ` (1)` 等编号，返回实际路径。`overwrite:true` 仅用于用户明确请求替换原件。
- 替换原件在全自动模式也必须确认。使用主窗口关联的原生确认窗口展示准确文件路径，默认取消；关闭、取消、超时或无法显示确认时不覆盖。MCP 请求不提供原生工具调用 ID，不能生成一个无法绑定工具卡片的随机授权请求。计划模式在内核及MCP工具层拒绝写入。
- 工具写入前检查授权目录、已存在的真实父目录和符号链接；不允许输出通过链接逃出授权范围。
- 替换前保留同目录 `.zen-backups` 下带唯一名字的原件，并校验 SHA-256；单份备份上限128MiB，超出上限改为另存，不偷偷跳过备份。
- 临时文件完成后才发布结果；同目标写入串行化，新文件发布不覆盖并发产生的文件，替换前检查原件是否在等待/备份期间变化。
- 拒绝、取消、写入失败或并发变化不宣称成功，不自动删除用户原件。工具返回备份路径；受控输出与备份有持久快捷入口，切换会话后仍可打开。
- 办公文件默认先用 `prepare_file_copy` 制作独立、校验过的工作副本，再由技能/原生工具/Python 编辑副本。默认保存在工作区 `outputs/<名称>-edited.<扩展名>`，支持指定授权输出路径，自动编号避免重名。只读分析不复制，新建文件不多加一次准备步骤。单次上限128MiB，复制不是格式转换，不改变扩展名。
- 原生编辑确需替换原件时仍须先取得确认，再调用 `backup_file`；备份不是覆盖/删除授权。`backup_file` 只备份，不删除、自动恢复或回放操作。
- 常见 `rm/rmdir/del/Remove-Item` 删除命令沿用 OpenCode 原生权限规则要求确认，全自动模式不跳过。删除是独立授权，不从编辑、清理临时文件或全自动模式推断；优先回收站。本批没有新增通用回收站工具，也不声称命令名称匹配能识别全部脚本、别名或第三方工具中的删除。
- 这不是完整文件系统事务/沙箱，不拦截所有原生终端或第三方脚本写入，也不能防御另一个恶意进程任意改目录的全部竞争条件。原生操作继续受已有权限约束，发布、支付等外部操作不因本批改动获得新授权。
- 备份不自动清理、不自动覆盖恢复；由用户保留或显式处理。备份入口不标为语义/内容已验证。

## 4. 轻量环境与性能定位

- `environment` 按需提供实际日期、时区、平台、架构、工作区、已授权目录与桌面/文档/下载/临时目录的真实路径；不联网、不执行命令、不每轮注入变化信息。
- 返回系统路径只是信息，不是文件访问授权。
- 性能诊断只观察已有事件：本地准备、各页面阶段、实际首个可见输出/正文、上游请求数/等待响应头/请求耗时、原生重试事件、工具调用和未完成工具。
- 成功、失败和手动停止均记录性能摘要；产品MCP工具另记工具名、时长和失败状态，不记录参数或附件内容。沿用现有诊断包，不增加额外模型、测速或探活请求。
- 阶段时长是界面观察值；上游与工具累计时间可能重叠，不可直接相加，响应头时间不是首字时间。补读历史才发现的结果只能称“观察到”的时间，不能据此认定上游实际首字时间。
- 此性能摘要从OpenCode适配层启动本轮处理时计时，不含此前附件保存或前端渲染耗时；不是替换页面上用户点击发送到最终显示完成的计时口径。
- 无实际正文时首字时间为未知，不伪造0秒。诊断用于缩小问题范围，不承诺仅凭时间就能证明根因或提高缓存命中率。
- 正常回答下方继续沿用既有简洁Token/时间栏，不增加一排性能指标。

## 验证与生效

本批不改变原生循环、压缩、模型政策、渠道路由与旧助手只读边界，不启用微信、定时、长期记忆，不升级OpenCode，不修改版本号或推送。

自动化覆盖工具隔离、无启动搜索、原生技能清单字段、技能依赖/冲突/生命周期、搜索错误/超时/限流/解析、目录/链接/并发/拒绝/取消/备份、性能口径及UI状态。

最终执行结果：fork 隔离的3个分片覆盖393个不同测试文件，4926项通过、0项失败、5项跳过；最终专项19个文件、144项通过，数字不累加。lint（含类型、国际化及格式）、Electron 构建与 diff 检查通过。Windows 原生内核本地模拟 smoke 通过，9次模拟请求、0次付费请求。搜索测试使用 mock，没有实际调用公共搜索；smoke 的模拟 MCP 不证明公共搜索线上或所有产品工具实际语义。

默认 thread 全量整跑曾提前退出、未获得正常结尾，原因尚未确认，未计为通过或修改测试配置；最终全量结果采用完成的 fork 三分片报告。详细执行边界同步登记在渐进补齐清单中。

重启 `pnpm dev` 后测试。真实四家模型语义、公共搜索线上可用性、文件视觉质量及Mac安装包仍需真实环境验收；本地模拟通过不代替这些验收。

## 简短用户测试

1. 搜索：`帮我查一下本月上海有什么官方公布的展览，挑3个，告诉我日期和官网来源。查不到就说明，别编。` 不提交私密信息，核对网址与发布日期；搜索失败后继续发“你好”应正常。
2. 技能：设置→技能→选中一项→兼容检查。再发：`你现在实际能发现哪些技能？告诉我名字和来源路径，不用运行它们，也别安装任何东西。`
3. 文件：测试工作区发：`新建一个测试文件夹，做一份测试说明.txt，写“原件”，给我打开入口。` 再发：`把刚才这个文件改成“第二版”，可以替换原件，但先备份，给我结果和备份的打开入口。` 在默认模式核对授权，原件备份应仍为“原件”；另测拒绝授权后原件不变。
4. 环境：`现在本地日期和时区是什么？当前工作目录、桌面和下载目录在哪里？只告诉我，不用扫描文件或测试网络。` 再发“你好”不应新增环境查询。性能口径由自动测试与诊断证据检查，不要求用户手工计时。
