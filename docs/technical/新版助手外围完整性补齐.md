# 新版助手外围完整性补齐

日期：2026-10-12。适用 OpenCode 新助手。旧助手继续只读，旧微信/定时任务不开放。本批不改模型选择、原生执行循环、压缩、重试和版本，不新增模型请求。

## 一、无需错误卡的当前会话诊断

新版助手当前会话右上角“…”菜单提供“导出诊断包”。先确认隐私，再保存 ZIP。导出锁防重复点击；取消保存不会当作任务故障。

诊断绑定点击时选中的最新助手消息及关联用户消息，不导出完整历史、附件原件或其他会话。仍沿用有界脱敏、后台只读证据查询、采集超时与 ZIP 完整性校验。快照可能包含本轮文本、本地路径、工具输出和内核标准错误中的任务内容；发送给别人前需要检查。

- 有错误卡的既有导出：mode=error，保留结构化错误诊断。
- 菜单导出：mode=snapshot，保留导出时状态与真实已有错误，不制造空回复/超时/已失败结论。
- 无任务记录：明确 no-recorded-turn，没有请求证据不是连接失败。
- 运行中：刷新已运行内核中匹配该 operationId 的限量进程快照，不启动、停止、修复或重跑任务。
- 证据过期、采集失败、无后台查询权限、旧版本或软件整体崩溃：如实报告缺失，仍可导出已有证据。一个包不保证能查明所有根因，Mac 闪退可能仍需 .ips。

## 二、退出、重启和异常中断

所有实际任务入口已共享会话活动租约，准备阶段也计入忙碌；此外检查正在启动/执行的 OpenCode 进程。

真正退出的 before-quit 在停止进程之前拦截。非阻塞原生对话框默认“继续运行”，重复退出共享一份确认；取消或提示失败保留运行状态。确认退出才终止内核并清理。Windows/Linux 无托盘关闭不会先销毁窗口；托盘及 Mac 隐藏窗口包含全屏状态均保留渲染器和流。

软件重启和安装更新在 relaunch、强制退出或设置 installing/quitting 标志之前确认。取消更新安装保留已下载包，不报成模型失败。正常退出不能承诺撤销已完成的文件操作或外部动作。

首次读取新助手历史时，检查未完成助手消息：仅限上一程序运行、当前没有活动租约的消息。新的助手持久化写入带本次程序运行标识，避免用户调整系统时间导致误判；旧版本未带标识的待完成记录视为上次中断。乐观比较原始持久化内容后，把显示状态改为 paused，未完成块/工具改为暂停/取消，增加“软件关闭或重启导致中断，未自动重跑”提示。已完成块、原生会话 ID、文件、用户消息和旧助手记录均保留。若并发终态写入抢先发生，重新读取，不覆盖它。

这不是任务续跑机制。系统强杀、断电或进程整体闪退无法保证最后未保存的片段，不能替用户判断重复写文件/支付/发布是安全的；用户检查成果后主动继续。

## 三、通知与人工交接闭环

完成、失败、工具授权和浏览器登录/验证等人工操作使用已有助手通知开关，后台任务即使不足30秒也可提示。正在聚焦查看对应会话不再额外通知；查看其他会话可通知。用户停止、并发拦截不当作正常失败通知。

通知正文仅通用状态，不含会话名、提示词、输出、路径、网站或权限参数。操作编号与 agentId/sessionId 只用于有界去重和跳转，不含凭据。去重最多保留512项；原生重试不逐次生成失败通知。

系统通知和应用内提示均传可序列化 meta.assistantTarget；不依赖跨 IPC 的 JavaScript 回调。点击先用本地 API 在3秒内检查会话存在，再选择新助手和对应会话。已删除/服务不可用提示无法打开，绝不重建会话、自动重试、批准权限或恢复任务。组件卸载或新点击后，旧查询结果不能反向跳转。

浏览器人工交接不强行把新助手窗口置前，避免打断登录/验证码；现有“稍后/进入任务对话”提示仍保留。重复同一交接事件不会叠多个弹窗，新交接使用新请求编号。通知系统权限被系统关闭时仍可从应用内状态/任务卡处理，不要求软件绕过系统权限。

## 四、按需当前会话 Skill 清单

菜单“当前会话技能清单”只在点击时读取。已安装库、工作目录 .agents/skills 定义和已有进程的实际 /skill 清单分开记录来源。没有进程或还在启动，discovered=null；失败不能假装已加载。只查询本地原生清单，没有生成请求、额外技能注入或预热进程。

内核按实际 SKILL.md 路径匹配发现状态，不能凭名称相同就标为已加载。运行期间设置发生变化时提示“下一次用户主动任务刷新”，当前任务不被中断。禁止的原生 customize-opencode 不显示为可用。工作目录只读检查拒绝符号链接/超大文件，不返回全文技能正文。

定义检查只解析 YAML/JSON 数据，禁用 JavaScript 等可执行前言引擎和自定义对象标签，避免“查看技能清单”或“兼容性检查”意外执行第三方代码；文件最多256 KiB，YAML别名数量有界。此限制仅用于只读检查，不把检查失败变成任务自动拦截，不改OpenCode加载循环。

本轮调用取最新用户消息之后保存的原生 skill 工具事件；pending/streaming 参数不是已调用。成功、失败、取消与已发起分开。仅名称引用、其他工具和前轮调用不能算本轮使用。同名调用仅靠名称不能确认具体定义路径；直接 read SKILL.md 等场景也可能指导工作，所以“无调用证据”不等于“完全未使用”。

既有技能安装/启用/冲突/依赖检查入口保留，本批不自动安装、不解决同名优先级、不扩大权限，也不承诺任意第三方技能必定完美适配。

全量用 fork 三分片，另跑 lint、格式、i18n、类型、Electron构建、OpenCode Windows本地模拟。模拟不访问生产、不消耗付费Token。真实Mac窗口、系统通知权限和安装包仍由实际平台人工验收，不冒称已测。
