- [ ] 菜单里的“当前会话技能清单”能区分启用、内核发现和真实调用，不仅凭模型口头说用过某技能。没启动过内核时允许“未确认”，不为看清单请求模型。

第三方技能有依赖时，兼容检查不等于已经安装或连接外部工具；本轮不要求导入任意第三方技能都完美工作。

### 8.2 通知、托盘、真正退出

复用一个新的文件任务，发送后切换到其他页面或隐藏窗口：

- [ ] 隐藏/关闭到托盘时任务继续，回来可见结果。
- [ ] 开启助手通知时，完成/需要人工操作的通知能回到正确新版会话，不自动重跑或批准权限；正文不带私密任务内容。
- [ ] 关闭助手通知后不反复弹；系统禁止通知时，应用不能绕过系统权限。
- [ ] 任务未结束时尝试真正退出，选择继续运行后任务仍可工作。
- [ ] 再用可丢弃任务选择停止并退出，重开后显示中断/暂停，不无限转圈，不自动执行一次旧任务，已有成果不被删。
- [ ] Mac也做一次隐藏/返回和真正退出，这是Windows测试不能代替的。

### 8.3 普通/开发者模型与任务名额、旧记录

使用现有远端配置，不为了验收改生产名单：

- [ ] 普通模式新版模型下拉符合面板规则；开发者模式可选Provider中按现有规则放行的文字模型。
- [ ] 原会话模型下架时，如已有这种测试会话，使用远端默认/可用兜底，不以空模型提交。没有可用模型时说明如何配置，历史仍能看。
- [ ] 普通模式一个任务正在运行/等待授权时，另一个新版会话被名额提示拦住；停止前一个后能执行。
- [ ] 开发者3个任务的边界已自动测过；如果要实际使用并发，再用不同新子文件夹补3任务/第4个拦截。不并发覆盖同名文件。
- [ ] 弃用助手发送按钮灰色，提示旧助手已停止使用，回车和旧重试不能发任务；开发者模式也一样。
- [ ] 如你有旧记录，任选一个普通、无外部副作用的会话“在新版继续”。复制时不请求模型、不执行旧任务，旧记录不变；你发新指令后新版能理解背景。
- [ ] 微信、定时、心跳旧入口关闭，已有绑定/计划不自动恢复，历史与配置没有被删除。

大段旧历史副本是有界背景加可回查档案，不是无损复制旧SDK内部记忆；不以“记住所有旧细节”作为这一步的保证。

## 9. 真正的长对话压缩专项（单独安排，不能省略成短问答）

这是目前最重要的真实语义未验收项。目标：同一新版会话至少发生两次原生压缩，最新纠正仍生效，之后还能完成工具任务、换模型、重启继续。

### 9.1 放入少量可核对的关键记忆

在准备长期使用的新版测试会话开头发送：

~~~text
接下来我们一直讨论这个测试项目。请记住：
项目叫蓝鲸；预算8000元；先选方案A；联系人林岚；交付日期2026年11月12日；主色蓝色；不要用红色；测试识别词是“青石桥”。
现在只确认，不创建文件。
~~~

随后发送：

~~~text
更正两项：预算改为6000元，方案改为B。其他不变，以本次为准。
~~~

之后在同会话做真实的方案讨论、文件分析等正常任务；可以使用你已有的新版长会话，但开头要能核对当时的关键信息。不要为了凑长度让模型反复吐无用文字或把同一附件重复上传几十次。

可用的自然任务：

~~~text
继续完善蓝鲸项目。帮我细化执行步骤、负责人安排、可能出现的问题以及应对方式。不要改预算、日期和配色；有不明确的信息先标为待确认，不要自己发明。
~~~

### 9.2 必须确认真的发生压缩

- 压缩不是“聊到第10轮”固定触发，而与实际上下文预算相关。
- 短消息几十轮也可能没到阈值；把文件存进工作目录不等于整份文件占进模型上下文。
- 看到整理/压缩状态后，可从该轮菜单导出诊断ZIP。在timeline.json搜索事件“native-compacted”，这是已完成原生压缩的证据之一；只有等待文案或一句“我已整理”不算。
- 第一轮压缩后保存对应ZIP/时间；继续任务直到第二次，再保存第二轮的证据。每次导出绑定本轮，不要求一个ZIP包含全部历史事件。
- 没证据时记“尚未触发/未确认”，不要为了完成验收擅自修改主力模型预算或手动调用内部接口。
- 若想快速做两次真实压缩压力测试，需要另行安排隔离测试和额度预算；不要默认消耗几十万Token。

### 9.3 两次压缩后的核对

第一次压缩后发送：

~~~text
只根据我们的对话，告诉我蓝鲸项目的最新预算、最终方案、联系人、交付日期、主色、禁用颜色和测试识别词。不确定就说不确定，不要把旧方案当成最终方案。
~~~

正确：6000元、B、林岚、2026年11月12日、蓝色、红色、青石桥。

随后更正：

~~~text
再更正一次：预算调整为5500元，交付日期推迟到2026年11月15日。其他不变，以这次为准。
~~~

第二次压缩后重复核对，正确：5500元、B、林岚、2026年11月15日、蓝色、红色、青石桥。

再发送：

~~~text
按我们现在最终确定的信息，创建一份新的“蓝鲸最终方案.docx”。只写已经确认的项目名、预算、方案、联系人、日期、配色和识别词，不要重新采用旧结论。不要覆盖旧文件，完成后给我入口。
~~~

- [ ] 第二次压缩后记忆正确，Word真实生成且内容正确。
- [ ] 换另一家模型继续核对，仍按5500元/11月15日/B。
- [ ] 正常退出、重开原会话，再核对仍正确。
- [ ] 压缩失败时不空白成功、不丢历史、不反复自动重放文件操作；遇到问题导出当轮ZIP。
- [ ] 项目私有信息不串到另一个全新会话。

本轮模拟已验证原生压缩通路，但没有验证这份真实答案。不承诺百分之百记忆，也不能以百分之九十目标掩盖关键纠正全部失效。

## 10. 备份/恢复与并发文件边界（有隔离环境再做）

### 10.1 只检查运行中保护

在任务运行或等授权时尝试备份/恢复，确认应先停止或等待；数据不能先被改掉，软件不能替你停止或重跑任务。取消选择/确认框后，原任务继续。

清空属于破坏性操作：主力安装上不测试清空，连“验证是否会拦截”也留给隔离环境。

### 10.2 同电脑精简恢复，必须可丢弃数据

先确认测试安装使用独立、可删除的数据目录。仅创建新工作子文件夹不代表隔离了软件数据库；不确定就不要恢复。

1. 另建独立的备份测试会话，不复用第9节长对话。保存“蓝鲸、4200元、2026年10月30日”三项记忆，生成一个新Word。
2. 等全部任务结束，做精简备份，保留备份ZIP。
3. 恢复到同一个测试环境并重启。
4. 查看记录、技能及本机已有文件仍在，在原会话发送：

~~~text
不要读文件。根据我们原来的对话，告诉我项目名称、预算和交付日期。
~~~

正确：蓝鲸、4200元、2026年10月30日。

- [ ] 不仅显示记录还在，原生记忆也能继续。
- [ ] 精简包省略的本机已有附件/成果不会被误删。
- [ ] 恢复成功或取消后，能正常再开任务，不永久锁住。
- [ ] 不进行强杀、断电或故意破坏数据库测试。

备份可能含凭据，绝不能把完整备份当脱敏诊断ZIP发给别人。

### 10.3 本轮没有做出的能力，不按“失败”反复测

- 跨电脑/Windows到Mac的绝对路径、外部工作区和原生绑定自动迁移：尚未完整实现，不保证无损继续。
- 精简备份没包含的附件，换电脑可能打不开；完整备份也不会自动带走Data之外的全部文件。
- 默认新版多个会话仍可能共享工作目录，不保证所有原生终端/第三方脚本写入具有统一事务保护。
- 任意第三方MCP、重新接入微信/定时、跨会话长期记忆：本轮未开放，不作为当前基础版的验收项。
- 批量无损搬迁全部旧SDK历史、自动回滚外部文件：没有这样的保证。
