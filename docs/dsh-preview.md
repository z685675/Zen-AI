# DSH 内测助手

此入口用于在相同的 Zen AI 助手界面下比较 OpenCode 和 DeepSeek Harness 的执行体验。

## 进入方式

1. 启动本次修改后的开发版，打开「设置 → 常规设置」，滚动到「内测功能」。
2. 点击「验证」，输入约定的内测密码。
3. 点击「进入内测助手」。首次会下载并验证独立运行环境；页面显示当前阶段，可通过「关闭内测」取消。
4. 准备完成后自动进入助手页面，侧栏也会出现「DSH 内测助手」。选择现有服务商和模型后即可发送任务。

每次重新启动软件都需要重新验证。关闭内测会停止内测任务并隐藏入口，已有会话和文件仍保留。密码由主进程核验，不会作为解锁状态永久保存。

## 建议先测

- 简单问答：确认流式回复和正常结束。
- 文件任务：要求在工作目录创建文件，确认文件卡可以打开、内容符合要求。
- 权限确认：触发需要确认的操作，分别尝试允许和拒绝。
- 连续问答：继续上一轮、切换会话再返回，确认上下文、草稿和浏览位置。
- 执行途中追加问题：先排队，再用「引导」改变本轮方向；停止后确认不会自动重放工具。
- 浏览器任务：使用原有接管与授权界面，登录或验证由用户完成。

两个助手分别保存会话和工作目录；普通模式最多同时运行一个助手会话，开发者模式最多三个，两种内核共用此限制。任务内部的工具并发不受这项会话数量限制。

## 本轮范围

- OpenCode 已更新至 1.19.6，继续作为默认助手。
- DSH 固定为 0.2.2-alpha.3；目前支持 OpenAI 兼容接口和 Anthropic 接口。该版本原生适配器不支持 Gemini、Bedrock、Vertex 等接口的专有协议，不会自动改协议冒充兼容。
- 使用现有模型、文件、浏览器、已启用技能及选定 MCP 的入口，不提供插件市场页面。
- DSH 的原生历史是事件日志。删除历史时会明确确认删除这一轮及后续轮次；不会只删除画面上的消息而保留对应上下文。
- 本轮接入执行内核，不包含单独的 Super-agent GitHub/飞书工作流配置。
- 首次下载的依赖保存在本机应用数据目录；正式安装包仅增加小型桥接文件与锁定元数据，不携带整套 DSH 依赖。

开发版执行 `pnpm dev`，或安装 v1.1.85 及后续版本后，即可按上述步骤验证入口。
