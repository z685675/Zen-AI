# 微信助手扫码绑定修复验收

## 本次修复

扫码登录成功后，确认绑定仍可能失败。原因是后台误用了未初始化的界面翻译模块，生成的“微信会话”名称为空，无法写入数据库。

现在会话名称和微信提示消息统一使用主进程翻译。后台会记录脱敏错误，界面会显示连接失败原因；确认绑定失败的提示不会被每 5 秒的状态刷新清掉。

本次不修改已有微信账号、凭据或历史记录，不启用旧助手的微信接入。

## 人工验收

先重启包含此次修复的开发版；已安装的旧安装包不会自动包含源码修复。

1. 打开新版助手的微信接入设置，点击扫码连接，在手机确认登录，再点击“确认是本人账号”。应显示已连接，并可打开“微信会话”，不再提示笼统的添加失败。
2. 在微信发送“你好，请只回复：微信连接成功”。应收到回答，电脑上的对应会话也应保留记录。
3. 在微信发送“新对话”。应提示已开始新对话，新会话可以继续聊天，旧会话记录仍可查看。发送“停止”时，应有正常中文提示，而不是空消息。
4. 保持连接并正常关闭、重新启动软件。应恢复已授权连接，不应重复建立空会话。重新扫码或更换账号时，仍必须确认本人身份。
5. 主动断开连接，再扫码连接并确认。应可重新添加，原先的历史会话和文件不得被删除。

如仍失败，请提供点击“确认是本人账号”后的提示和对应时间段的日志，不要提供二维码、微信凭据或 API Key。

## 自动化覆盖

- 模拟微信登录后确认绑定，使用 SQLite 检查非空会话名称与绑定持久化。
- 本地保存失败后保持待确认状态，无须再次扫码即可重试。
- 未登录不能确认绑定；已授权账号重连不重复建会话。
- 断开后重新绑定保留历史；新建微信会话和控制消息均使用正常翻译。
- 界面显示连接失败原因；后台状态刷新不掩盖绑定失败。
- 关联回归包括消息去重、身份校验、定时任务、投递队列和共享并发限制。

自动测试使用模拟微信传输，不登录真实微信、不调用付费模型；真实扫码和手机收发需按上面的步骤手工验证。

## 微信、定时任务重复回答与电脑继续会话

本轮新增修复：

- 微信与定时任务的消息统一由后台保存；界面仅展示同一组固定消息编号，避免重复落库。
- 后台轻量会话不再因为未注册浏览器工具而每轮重启；必须重启时，先确认旧进程退出，再打开原有历史数据库。无法确认退出时停止启动，不删除或重置历史。
- 电脑继续已绑定的微信会话时，把本轮提问与最终答复按顺序加入微信投递队列。只镜像结果，不再次执行提问。
- 每轮回传使用固定编号去重；暂停同步、换绑或删除绑定后，不把旧任务结果发给新对象。其他普通会话不回传。
- 本地内核启动失败单独归类，不再误判为模型服务故障。
- 后台保存的回答保留可读模型名、首次工具/文字响应时间与总用时，切换页面后仍可查看。

手工步骤（需要真实微信）：

1. 手机发送“你好，请只回复：手机测试7319”。打开电脑对应微信会话，确认一条提问、一条回答。
2. 电脑在同一会话发送“请记住本次编号7319，并只回复：电脑继续成功”。手机应依次收到这条提问与最终答复，且各一次。
3. 手机追问“刚才电脑让我记住的编号是什么？”应能继续同一会话，回答7319。
4. 回答期间切换到其他会话，再切回来；完成后再切一次，确认没有重复回答，时间与用量不丢失。
5. 新建普通桌面对话发送“这个消息不要同步到微信”；确认手机没有收到该会话内容。
6. 在微信会话暂停同步，再从电脑提问；电脑可继续，手机不应收到新内容。重新开启须按界面确认，不能补发已被取消的旧队列。
7. 手动触发一个定时任务，在任务执行时打开其会话；确认仅一条回答，切换页面后不增加重复记录。
8. 连续从手机和电脑交替追问，确认没有本地内核启动失败。若电脑提交时已有任务正在运行，应遵守现有排队/并发提示，不能偷偷重复执行。

注意：这次不会自动删除历史中已产生的重复记录，以免误删合法的相同回答；请用新的提问判断修复效果。

## 聊天页同步提示与首页入口

- 首页快捷入口按“微信助手、定时任务、技能”排列。
- 聊天输入框上方不再显示大型同步说明卡片；使用范围、连接状态、暂停同步与投递处理仍在微信助手设置页查看。
- 手机发起或电脑继续微信会话，回答完成且该轮全部文字/文件投递均收到微信服务确认后，仅在最后一条模型回答右下方显示淡色“同步完成”。等待、失败或不确定时不显示，不使用“同步中”，也不挤占诊断包操作区。
- “同步完成”表示记录已保存且微信服务确认接收，不表示对方已读。暂停同步、换绑或非微信会话不显示此标识。

手工补充验收：

1. 手机和电脑各发一轮：回答过程中无完成标识；手机收到最终答复后，电脑最后一条回答出现“同步完成”。
2. 切换会话再返回、重启软件后再查看，标识应来自后台实际投递状态，不得因重新打开而补发消息。
3. 在设置页暂停同步，再从电脑提问，完成后不得显示“同步完成”；恢复或换绑也不得把旧任务冒充为新绑定的完成记录。
4. 若一轮包含多段文字或文件，在全部发送成功前不显示完成。失败/不确定投递仍到微信助手设置页处理，不自动重复发送。
