# 客户端更新链路集中检查记录

日期：2026-11-02。检查对象：基于 1.1.79 工作区修复的客户端更新代码，随后纳入 1.1.80 草稿构建。

本轮沿着“发现更新 → 下载 → 提示安装 → 退出旧版 → 启动安装器 → 文件替换 → 失败恢复”集中复核。以下区分已经完成的代码、自动化和隔离测试，以及正式安装包仍需完成的实机验收。集中检查阶段没有公开新版本，后续构建保持草稿，测试后再决定正式发布。

## 已修复和验证的行为

| 环节 | 修复后行为 | 验证方式 |
| --- | --- | --- |
| 自动发现更新 | 后台下载，安装包准备完成后再提示安装 | 更新服务状态及事件测试 |
| 手动检查更新 | 先提示下载，同一个窗口显示进度，完成后转为安装按钮 | 更新服务、弹窗测试和真实 AntD 界面测试 |
| 重复点击、切回页面 | 检查和下载共享正在执行的操作；恢复缓存、获取新版本和安装不会互相覆盖 | 并发及状态切换回归测试 |
| 下载失败后重开弹窗 | 补读实际状态，恢复重试按钮；状态读取失败也不会一直卡在下载中 | 弹窗与状态 Hook 回归测试 |
| 长更新说明 | 说明独立滚动，操作按钮保持可见 | 1024×600 和 720×480 浏览器界面测试 |
| 点击安装 | 合并重复请求；等待正在进行的下载；启动失败或取消权限确认后允许重试 | 服务与实际安装 SDK 的启动逻辑测试，替换操作系统进程创建边界 |
| 安装提示窗退出 | 安装启动期间禁用 Esc 和取消操作，失败后恢复 | 弹窗回归测试 |
| 关闭 Windows 旧版 | 等待旧进程退出；按完整安装目录和进程身份清理，防止路径相似或 PID 复用造成误关 | 真实 32/64 位进程夹具、进程身份测试及原生 NSIS 等待夹具 |
| Windows 文件替换失败 | 替换前保留旧版；失败恢复文件与注册信息；异常中断后可恢复；中文路径保持可读 | 临时目录、独立测试注册表键及已编译 NSIS 失败回调测试 |
| Windows 更换安装目录或范围 | 升级必须沿用原目录及当前用户/所有用户范围；不安全的迁移在替换前停止并给出中文提示 | 原目录、范围切换、旧卸载入口、不匹配卸载位置及中断后迁移测试 |
| 恢复期间的注册信息 | 还原旧值；删除失败安装新建而原先不存在的产品注册表键 | 真实测试注册表恢复测试 |
| 旧备份清理受阻 | 保留有归属记录的旧备份，后续升级仍能保护当前版本；不删除未知目录和链接指向的文件 | 文件占用、目录链接、无效记录和重复升级测试 |
| Mac 本地安装包 | 校验发布的 SHA512、大小和 DMG 格式；不接受网页错误内容或截断文件 | 真实临时文件与校验测试 |
| Mac 缓存与新版本竞争 | 先协调恢复再检查，更新的版本不会被旧缓存覆盖；相同版本共享一次准备操作 | 并发恢复、启动计时及下载测试 |
| Mac 下载中断 | 限制响应头等待及连接空闲时间；失败关闭连接并清理临时文件后再重试；限制重定向次数 | 超时、重定向和部分响应中断测试 |
| Mac 打开安装包 | 打开失败可转到 Finder；仅挂载 DMG 不视为安装完成，重启旧版后保留待更新状态 | 服务和持久状态测试，替换 Finder/系统打开边界 |

迁移安装位置的处理方式：先通过系统卸载旧版并保留个人数据，再安装到新位置。升级安装过程不自动迁移目录和安装范围。

## 仍需正式安装包实机验收

1. Windows 从已公开旧版实际升级：托盘退出、普通权限及管理员权限、保留对话和设置、安装后启动与再次更新。
2. Mac 在目标架构设备上实际挂载 DMG、替换 Applications 内应用、启动新版本并确认待更新记录清除。

Windows 自动化和隔离测试不能代替 Mac 设备验收；安装器编译或进程成功启动也不能单独证明完整升级已经成功。
