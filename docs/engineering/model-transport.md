# AI 对话与智能助手的连接选择

AI 对话的 Provider fetch 与新版智能助手的 OpenCode 网关共用 `ModelApiTransport`。只对 Zen 托管域名的 HTTPS 模型接口和只读连通性探测启用。图片工作台通过同一个线路选择器接入。第三方 Provider、自定义 IP 配置及浏览器自动化不改变。

由 API 面板独立的“客户端连接线路”下发物理入口。默认沿用 Cloudflare；管理员启用自动模式后，客户端优先访问带有效 IP 证书的 HTTPS 源站，域名仍用于界面、Provider 身份及 JSON 导入。服务器 HTTPS 入口需要另外部署，客户端不会修改隧道。

## 网络与代理

- 每次发送前通过 API 所在的 Electron 默认会话解析代理。明确返回 `DIRECT` 时，使用独立的 Undici 连接池；配置了代理、返回代理候选列表或代理状态不明时，沿用原有代理路径。
- 使用正常 DNS、原始域名、SNI 和证书校验。DNS 同时提供 IPv4/IPv6 时优先 IPv4；TCP 建连阶段采用 Node 的自动地址选择，必要时尝试 IPv6。没有固定 Cloudflare 节点或源站 IP。
- 地址切换发生在 HTTP 请求写入前。fetch 失败、HTTP 错误或流中断后，此通道不会再次提交生成请求；上层原有重试/备用模型策略仍由原逻辑控制。
- 连接池允许复用连接。仅设置 10 秒建连超时，不移植图片下载的首包/分块超时；模型推理、流式响应的等待和取消继续由原有任务 AbortSignal 控制。
- 不修改全局 dispatcher，也不修改浏览器会话的代理。浏览器继续遵循自己的系统网络设置。Clash TUN 等系统级流量接管仍由操作系统控制。

## AI 对话的流式桥接

Renderer 原生 fetch 无法单独指定地址族，因此托管模型的 JSON 请求通过受限 preload IPC 交给主进程。start 返回响应头，pull 按需返回一个分块，cancel 终止同一请求；没有把完整回答缓存后再返回。保持 HTTP 状态、请求 ID、SSE 内容与顺序，移除已经解码的传输长度/压缩头。

入口仅接受默认 API 会话中的应用主 frame，拒绝网页、iframe 和浏览器分区。每个窗口拥有独立请求集合，窗口销毁、导航或 renderer 崩溃会取消未结束请求。主进程校验域名、路径、方法和参数，并拒绝 Cookie、Host、Connection、Content-Length 注入。仍使用原始 API Authorization；不会转发浏览器 cookie。

旧 preload 尚无桥接、Request 对象、非字符串 body、显式携带 cookie 或不在范围内的 URL 会在发起请求前保留原 fetch，不会先发送再回退。

## 诊断

在现有任务诊断中记录连接策略、DNS 耗时和地址数量、TCP/TLS 建连耗时、实际远端地址族、连接复用、开始写入及请求发送完成。不记录 API Key、提示词和响应内容。事件只能说明客户端到 API 的连接阶段，不能据此判断 API 到上游的等待原因。

连接阶段事件进入现有的有界优先保留队列，避免长任务的高频进度日志挤掉最初的连接证据；仍受既有事件数和总字符数限制，超限时保留丢弃计数。

## 验证

自动测试覆盖 IPv4 优先、发送前回退 IPv6、连接复用、POST 断线不重发、代理保留、SSE 分块、取消、长推理等待、跨窗口隔离、IPC 主 frame 校验及 OpenCode 网关接入。

2026-11-17 已在独立 Windows Electron 进程中验证真实 IPC 的中文分块、取消、断流、HTTP 错误、窗口关闭取消和不可信页面拒绝，并通过页面桥接完成公网 `/api/status` 的 HTTPS 读取。只读对比的新旧路径均成功，耗时随当时线路波动，不能据此承诺模型请求始终提速。此验证不触发付费生成，也不代替 macOS 安装包回归。

开发版须完整退出后重新运行 `pnpm dev`，使主进程和 preload 同时生效。人工回归建议分别验证：AI 对话短回复、长输入与中途停止；智能助手工具调用及取消；API 显式代理；助手浏览器的系统代理。网络对比须使用同一客户端、同一 API 和接近的时段，模型首字受上游负载影响，不能把单次变化全部归因于地址族。

## 远程线路规则

配置由原域名 `/api/client/connections` 提供，使用 HTTPS 验证、禁止跳转、8 KiB 读取上限和一分钟刷新间隔。只接受递增版本及公网 IPv4 HTTPS 源站，校验完整结构；上次有效配置缓存在主进程 ConfigManager。旧 IP 不作为配置发布来源，避免其失效或变更后成为新的信任来源。

每次发送前选择线路。首次直连前用无令牌的健康检测核对部署标识；健康结果有效一分钟。直连的连接、读取失败及没有 API 请求 ID 的网关错误会触发两分钟冷却，新请求改走 Cloudflare。冷却后探测至少间隔三十秒，连续两次成功才恢复。用户取消不算线路故障；HTTP 账号或模型错误不算线路断开。

切换器从不重发已经提交的 POST。已有图片任务只按 submission ID 查询结果、按 Range/ETag/哈希恢复下载。配置更新不打断已开始的请求；强制 Cloudflare 从下一次同步后的新请求生效。模型诊断优先保留 connection-route，图片下载历史也包含实际入口和配置版本。

模型、额度、策略、能力、诊断查询和图片工作台受控 API 接入；后台模型事件通知仍使用原域名。浏览器网页、第三方模型、安装包及热补丁下载不进入本选择器。操作及验收步骤见相邻 Zen-API 仓库 docs/client-connections.md。

断流时，AI SDK 适配器收到错误后立即返回已有错误状态，不再等待可能永不结束的最终文本 Promise；同时处理最终 Promise 的后续拒绝，防止未处理异常。部分内容继续由已有消息块保存。
