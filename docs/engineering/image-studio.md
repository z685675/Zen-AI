# 内嵌图片工作台

绘画入口保留“图片工作台 / 本地图片”切换，工作台沿用选中 Zen 服务商的密钥。现在默认显示客户端自带的“图片画布”，详见 [本地图片画布](image-canvas.md)。不会迁移或删除旧图片数据。

网页与后台任务在 Zen-API 实现，详见同工作区 `Zen-API/docs/image-studio.md`。需要先更新服务端，客户端才可连接；连接失败时提示重新连接，并可切回本地页面。部署后，浏览器也可访问服务端 `/studio/images`。

`ImageStudioService` 为工作台建立独立 WebContentsView，启用 sandbox、contextIsolation、webSecurity，关闭 nodeIntegration，且不加载任何 preload。网页没有主应用的 IPC、任意文件读写、Shell 或聊天执行权限。上传和下载使用浏览器原生文件对话框；下载限定同源作品接口和受支持的图片类型。跨域页面跳转、弹出窗口与浏览器权限请求被拒绝。

主窗口 preload 只增加 open/resize/close/setVisible 四个给本地 renderer 使用的接口，主进程验证调用者确实为主窗口主 frame。API Key 仅用于主进程请求一次性交接码，不进入网页 JavaScript。按 origin 与 key 哈希隔离浏览器分区；多个密钥可以在页头显式选择，默认使用第一个，避免每次重连轮换身份导致历史变化。切换页面或密钥时关闭旧视图，晚到的网络响应不能重新挂载视图。页面尺寸转换考虑主窗口缩放比例；本地弹窗或下拉菜单打开时暂时隐藏原生视图，防止遮挡本地界面。

浏览器端负责表单与作品浏览；已提交任务的生命期属于服务端。关闭视图不会中断任务；不确定请求的恢复沿用同一个提交 key。当前工作台只提供下载和继续编辑，没有为远程网页开放发送聊天或执行本地操作的通用桥接。

验证：桌面 lint（含类型、i18n、格式）和生产构建通过；全量测试 499 个文件通过，5962 项通过、9 项跳过。另补充的主进程视图隔离与迟到响应测试，以及共享 URL/尺寸校验测试共 4 项通过。未在生产账户发起付费图片生成。
