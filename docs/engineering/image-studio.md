# 内嵌图片工作台

> 2026-10-25 产品边界：桌面已移除“服务端工作台”内嵌演示入口及 `ImageStudioService`，仅保留本地图片工作台和旧本地图片。
> API 的图片任务、查询、归档和鉴权接口仍为本地工作台所用，不随桌面演示页面删除。下文涉及旧网页嵌入的步骤仅作历史记录。

## 本地工作台的生图前置请求（2026-10-26）

- 服务端声明 `asset_reuse: true` 时，本地按服务地址、当前密钥和请求头的哈希隔离素材缓存。已上传的参考图及新下载的作品按内容哈希记住远端素材 ID，重启后仍可复用；本地保存的等效 PNG 也会建立对应关系。经过 EXIF 旋转的输出保守地重新上传。
- 每次命中先鉴权 `HEAD /api/image-studio/assets/:id`，服务端确认当前用户/密钥有权访问且文件存在、大小正确，只返回状态，不传输图片。检查失败后退回正常上传；旧服务端未声明能力时完全沿用上传路径。缓存仅保留最多 1000 条、30 天，不包含密钥和图片内容，损坏或写入失败不影响任务恢复。更新前的历史图片首次作为参考仍需上传，之后可复用。
- 上传成功会记录固定接口、submission ID、响应头等待/响应体读取及总耗时；作品下载记录素材 ID、字节数和同类计时。任务轮询不逐次记录成功日志。服务端新增 `image studio asset timing` 与 `image studio upstream timing` 日志，能按 submission ID / job ID 对齐，详见 API 工程文档。此改动不重发生成请求，不改变计费边界。

- Zen 服务商使用 `GET /api/image-studio/bootstrap` 读取配置，再使用 `POST /api/image-studio/assets` 上传参考图，最后以 `asset_ids` 创建任务。上传图片本身不调用图片模型，因此不会出现在模型用量日志里。
- 界面分别显示读取配置、上传参考图和等待服务端处理。配置读取每次最多 30 秒，参考图上传每次最多 120 秒；仅网络中断、超时、408、429 和 5xx 可自动补试一次。永久拒绝和无效响应不自动补试。
- 只有非计费的准备请求可以补试，`POST /jobs` 绝不自动重发。创建任务前先持久化 submission ID 和可能已提交的标记，响应丢失后只查询同一任务。
- 准备阶段尚未提交时失败或重启，记录为失败而不是结果待确认；不能显示可能重复计费或误称直连接口。旧版不确定记录不擅自推断是否计费。
- 诊断保留失败阶段、固定接口路径、错误类型、网络错误代码（若可获取）、HTTP 状态、每次超时上限、耗时和尝试序号。原始异常、响应体、完整 URL 和鉴权信息均不进入诊断。
- `pnpm exec tsx scripts/image-studio-transport-smoke.ts` 用真实 Electron 网络层向本机模拟服务上传约 3 MB 的图片，逐字节核对参考图、任务中的参考图编号与结果下载，并验证重复引用、缓存重启后的作品引用只做 HEAD 检查而不重新上传；不读取用户凭据，不产生付费调用。

绘画入口保留“图片工作台 / 本地图片”切换，工作台沿用选中 Zen 服务商的密钥。现在默认显示客户端自带的“图片画布”，详见 [本地图片画布](image-canvas.md)。不会迁移或删除旧图片数据。

网页与后台任务在 Zen-API 实现，详见同工作区 `Zen-API/docs/image-studio.md`。需要先更新服务端，客户端才可连接；连接失败时提示重新连接，并可切回本地页面。部署后，浏览器也可访问服务端 `/studio/images`。

`ImageStudioService` 为工作台建立独立 WebContentsView，启用 sandbox、contextIsolation、webSecurity，关闭 nodeIntegration，且不加载任何 preload。网页没有主应用的 IPC、任意文件读写、Shell 或聊天执行权限。上传和下载使用浏览器原生文件对话框；下载限定同源作品接口和受支持的图片类型。跨域页面跳转、弹出窗口与浏览器权限请求被拒绝。

主窗口 preload 只增加 open/resize/close/setVisible 四个给本地 renderer 使用的接口，主进程验证调用者确实为主窗口主 frame。API Key 仅用于主进程请求一次性交接码，不进入网页 JavaScript。按 origin 与 key 哈希隔离浏览器分区；多个密钥可以在页头显式选择，默认使用第一个，避免每次重连轮换身份导致历史变化。切换页面或密钥时关闭旧视图，晚到的网络响应不能重新挂载视图。页面尺寸转换考虑主窗口缩放比例；本地弹窗或下拉菜单打开时暂时隐藏原生视图，防止遮挡本地界面。

浏览器端负责表单与作品浏览；已提交任务的生命期属于服务端。关闭视图不会中断任务；不确定请求的恢复沿用同一个提交 key。当前工作台只提供下载和继续编辑，没有为远程网页开放发送聊天或执行本地操作的通用桥接。

验证：桌面 lint（含类型、i18n、格式）和生产构建通过；全量测试 499 个文件通过，5962 项通过、9 项跳过。另补充的主进程视图隔离与迟到响应测试，以及共享 URL/尺寸校验测试共 4 项通过。未在生产账户发起付费图片生成。
