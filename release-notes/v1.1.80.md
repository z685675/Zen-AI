# Zen AI v1.1.80 更新说明

本次主要完善软件下载更新、安装与失败重试体验，并新增在软件内按版本浏览更新说明的入口。

## 下载更新更清楚

- 自动发现新版本时，先在后台下载，准备完成后再提示安装。
- 手动检查更新时，先选择「立即下载」，在同一窗口查看下载进度、大小和速度，完成后再选择安装。
- 更新说明可以单独滚动，较小窗口下也能看到操作按钮。
- 切换页面、重复点击或下载失败后重新打开提示窗，能正确恢复当前状态并继续操作。

## 安装与重试更稳妥

- 改善 Windows 点击安装后没有反应、旧版无法完全退出，以及取消系统权限确认后不能重试的问题。
- 替换程序文件前保留旧版，安装失败时可恢复；升级意外中断后再次运行安装程序，也能继续处理。
- Windows 升级请沿用原安装目录和原安装范围。需要迁移时，请先卸载旧版并保留个人数据，再安装到新位置。
- Mac 会检查安装包是否完整，避免打开未下载完成或无效的文件；打开安装包失败时，可到 Finder 中继续操作。
- 改善下载中断、旧安装包缓存与新版本冲突等情况，失败后可以重试。

## 在软件内查看历史更新

在「设置 → 关于我们 → 更新日志」中，可以按版本阅读更新说明。已保存的说明可在本地查看，联网时会尝试同步最新内容，方便跨版本升级后了解之前的变化。

本次包含安装程序改进，请使用完整安装包升级。安装前建议先完成正在运行的任务；Mac 用户请选择与电脑芯片匹配的安装包。
