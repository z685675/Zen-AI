# Zen AI v1.1.88 更新说明

## 统一侧栏和外观

AI 对话、智能助手和图片工作台共用同一条侧栏。按 `Ctrl+B` 或 `⌘B` 可以折叠侧栏，为当前页面留出更多空间。「更多工具」默认折叠，模型状态和用量可以从侧栏底部打开。

在「设置 → 显示设置」里可以选择 Codex Workbench 或 Zen Paper，两套主题均支持浅色、深色和跟随系统。

## 对话与任务更易浏览

AI 对话与智能助手采用统一的输入区和消息布局。智能助手的工具调用和子任务可在时间线里展开查看。会话有文件变更时，可从顶部打开面板查看差异。

「旧对话」位于智能助手列表顶部。可以查看、导出或在新版继续，也可以删除单条记录。删除整个文件夹会清空旧对话，包括已归档的记录，确认后无法撤销。

## 图片和视频工作台

图片工作台跟随应用主题，折叠侧栏后画布会随窗口调整。配置支持的视频模型后，可以在视频工作台生成视频、查看任务进度并保存结果。

## 升级方式

请使用完整安装包升级。安装前请完成或停止正在运行的任务，并备份重要会话和文件。
