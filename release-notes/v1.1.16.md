# Zen AI v1.1.16

这次更新围绕“智能助手”做了一次比较大的产品化升级，同时补强了微信接入、会话稳定性、图片生成入口、文件操作安全和发版前稳定性。

## 重点更新

1. 全新的“官方助手”体验
- 内置“官方助手”，作为智能助手的默认主入口。
- 官方助手不可删除，但支持编辑模型、提示词和配置。
- 旧 Agent 保留历史会话继续使用，新建会话能力收口到官方助手。
- 智能助手首页、会话列表、快捷入口和整体视觉做了简化，减少干扰。

2. 微信接入更完整
- 智能助手首页新增微信接入快捷入口。
- 扫码后默认绑定官方助手，并返回智能助手页面。
- 桌面端消息和助手回复支持同步到微信，并显示同步状态。
- 微信定位为远程文字对话通道，图片和文件建议回到桌面端处理。

3. 会话稳定性提升
- 修复刷新后智能助手历史会话不回显的问题。
- 修复聊过之后点击新建对话无响应的问题。
- 修复会话切换时短暂闪到首页的问题。
- 增强长任务、重试、中断后的兜底体验，减少卡在“三个点”的情况。

4. 图片功能调整
- AI 对话页不再展示图片生成入口。
- 图片模型不再出现在 AI 对话模型选择中，避免误用高成本图片模型。
- 图片生成页补充 gpt-image-2 相关背景、尺寸和安全级别说明。

5. 文件操作安全
- 对删除、重命名、覆盖、批量编辑等高风险文件操作增加备份提示。
- 默认建议先备份再执行，用户也可以明确选择不备份直接操作。

6. 基础能力补强
- 强化信息获取、文件输出、本地文件处理、任务可控性、结果校验、记忆/定时/跨设备等基础能力提示。
- 优化官方助手内置提示词，减少旧产品相关表述。
- 调整导航命名：“对话”改为“AI 对话”，“小龙虾”改为“智能助手”，“小龙虾官方助手”改为“官方助手”。

## 修复

- 修复官方助手编辑后可能被内置模板覆盖的问题。
- 修复官方助手编辑模型、提示词、配置后已有会话不同步的问题。
- 修复微信同步完成后仍显示未同步的问题。
- 修复深色主题下部分区域显示不一致的问题，并兼容升级后强制回到浅色主题。
- 修复用户消息编辑、用户消息重试、助手消息重试在智能助手场景下的异常。

## 验证

- 通过 OpenAPI 检查、Node/Web release 类型检查和生产构建校验。
- 通过微信/渠道、Claw、图片模型过滤、图片生成配置等关键测试。
