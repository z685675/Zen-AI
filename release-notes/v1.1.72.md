# Zen AI 1.1.72 更新说明

## 新版助手

- 新增基于 OpenCode 的“新版助手”，入口位于 AI 对话下方，内部助手名称为“智能助手”。模型继续使用已有 Provider，并遵循 API 面板的远端设置与开发者模式规则。
- 使用新版内核的会话记忆、自动压缩与工具执行机制，不再叠加 AI 对话的上下文整理流程。
- 接入已有技能、附件读取、Office 文件制作、网页搜索和浏览器操作；需要登录、验证或授权时，提示用户接管并继续任务。
- 补齐重试、分支、删除、话题管理及会话检查入口。
- 文件成果提供固定快捷入口，切换会话后仍可查找、打开和定位，不必展开工具记录。
- 优化等待、输出、工具执行和手动停止的状态提示，减少空白等待与重复提醒。
- 简化回答下方的 Token 与耗时展示，支持查看用量详情；发送和回答时间精确到秒，回答时间按实际完成时间显示。
- 补齐诊断 ZIP 导出、网络与工具错误说明，以及任务通知、退出提醒和备份恢复的运行中保护。

## 旧助手过渡

- 原助手改名为“旧助手”，内部名称为“请弃用旧助手”，仅保留历史查看、导出和文件访问，不能再发送或执行任务。
- 可将选定旧会话复制到新版继续，原记录保留不变；迁入的会话显示“迁移对话”标识。复制历史不会自动执行旧任务，也不保证迁入旧内核的全部内部状态。
- 旧版微信等外部接入、定时任务及心跳停止运行，保留配置和历史，不会在重启后自动恢复；这些功能尚未在新版重新开放。
- 普通模式最多同时运行 1 个新版助手任务，开发者模式最多 3 个。

## API 面板关联

- 新版请求携带 OpenCode 来源及本轮任务标识，配合更新后的 API 面板显示调用来源、助手用量与同一轮任务的日志分组。

## 测试提示

此次更新涉及新的助手内核，建议先用非重要文件测试普通问答、附件读取、文件制作和浏览器操作。Windows 与 macOS、不同模型及长对话压缩仍需分别验收；不要将自动化检查通过视为所有真实渠道和平台都已验证。
