# Zen AI 1.1.73 更新说明

## 修复与改进

- 修复 macOS 打包流程中的依赖符号链接处理，保留签名校验，并增加签名前检查；异常时会显示具体文件，方便定位。
- 新版助手复用后台环境准备功能，自动准备缺少的 Bun、UV 和 Zen AI 私有 Python 环境。准备过程不阻塞普通对话，不修改系统 Python，失败后会在后台有限重试，也可手动修复或导入离线 Python 运行包。
- 从智能助手环境检测与自动安装清单中移除 Git；不会卸载用户已有的 Git。需要 Git 的开发任务或第三方技能仍需相应工具。
- 改进环境准备中的状态、来源和失败提示，补齐离线导入按钮的翻译；Windows 后台安装不再弹出命令行窗口。

本版包含 1.1.72 的全部新版助手功能。新安装首次准备环境需要网络与一定时间，复杂 Python 任务请等待环境就绪后使用。
