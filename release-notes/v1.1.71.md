# Zen AI 1.1.71 更新说明

本次更新重点改善智能助手的任务执行、附件读取与故障诊断体验。

- 优化 Excel 附件处理，减少读取表格时的卡顿和内存占用；附件优先交给助手按需读取。
- 修复部分内部重试提示被当作回答显示的问题。
- 改善复杂任务的结果接收、异常恢复与超时处理，避免异常结束后一直等待或误判任务完成。
- 改善工具调用和图片结果传递，减少任务中断及信息丢失。
- 完善错误诊断包，补充请求链路、运行记录与服务端关联信息，便于定位故障。

配套 Zen API 更新改进渠道故障判定，避免因请求参数等错误误停用整个渠道。

建议重点测试 macOS 智能助手的 Excel 读取、文件生成和连续复杂任务。相关修复已通过自动化检查，具体 Mac 闪退场景仍需实际设备验证。
