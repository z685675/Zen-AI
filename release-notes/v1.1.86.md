# Zen AI v1.1.86 更新说明

本次主要改善对话连接、图片下载和长内容处理，减少网络异常带来的等待，让出错后的处理方式更清楚。

## 对话与任务连接更稳定

- AI 对话、智能助手和图片工作台支持跟随服务端配置选择连接线路，无需重新导入 API 配置。
- 服务端启用直连后，优先使用直连线路；检测到线路异常时，后续请求可回退到备用线路。
- 浏览网页仍使用电脑的系统网络设置，与 API 的连接设置分别处理。
- 改善流式回复中断后的状态处理，保留已经收到的内容，减少发生错误后仍一直显示等待的情况。

## 图片下载进度更清楚，恢复更可靠

- 下载时显示进度、已下载大小和速度，方便判断图片是否仍在传输。
- 改善已生成图片的取回与中断恢复，在满足校验条件时继续下载，减少因网络波动而重新生成。
- 完善图片下载的超时处理和诊断记录，便于排查长时间停留在“正在下载图片”的问题。

## 长对话与多附件处理改进

- 更准确地识别模型的输入、输出和上下文容量，并同步服务端更新的模型能力信息。
- 改善超长输入、多附件和 PDF 内容的整理方式，减少超出模型容量后无法正常回复的情况。
- 智能助手处理较长的用户输入和文件时，保留原始材料供后续读取，减少将全部内容一次性塞入请求的情况。

## 异常提示更容易处理

- AI 对话和智能助手的回复异常提示更统一，直接在外层提示重试、切换模型或导出诊断包联系管理员。
- 诊断包补充实际连接线路等信息，方便管理员区分本地网络、服务端和上游模型的等待。

本版请使用完整安装包升级。建议先完成或停止正在运行的任务，再安装新版。
