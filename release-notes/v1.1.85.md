# Zen AI v1.1.85 更新说明

本次主要完善智能助手的深度研究、文件制作和网页访问，并修复重复操作提示、文件无法打开等使用问题。

## 深度研究，更注重回答问题

- 深度研究适合了解陌生领域、比较不同方案、分析问题原因和制定行动计划。
- 助手会围绕你的目标检索资料、核对来源，再整理结论、依据、局限和建议，不再默认把研究变成批量获取论文。
- 默认直接在对话中交付报告。需要 Word、PPT 或 PDF 时，可以明确提出，或在报告完成后继续要求整理成文件。
- 改善网页正文和公开论文的读取，识别验证页面、访问受限和未取得正文的情况，避免把这些页面当成有效资料。
- 完善资料复用和长文分段阅读，减少重复获取已读内容。需要登录、下载论文或操作特定网站时，请明确说明目标，并按提示完成授权。

## 文件制作与交付更可靠

- 完善 Word、Excel、PPT 和 PDF 的制作指引与检查，改善参考文件修改和演示文稿的内容组织。
- 加强 Word 页数、默认样式及修改后复验，减少反复生成和排版返工。
- 修复部分文件链接无法打开、路径解析不正确的问题，加强交付前的文件检查。
- 更准确地识别命令执行失败，减少执行失败却显示成功、随后反复尝试的情况。

## 任务恢复与授权更清楚

- 改善重复操作的识别与恢复。拒绝某次重复操作后，助手可以根据反馈调整后续步骤，减少直接结束整个任务的情况。
- 完善工作目录权限处理，减少正常文件操作中的重复确认。
- 改善长任务、中断恢复及对话历史的保存，保留继续处理所需的信息。

## 浏览器与界面体验

- 助手浏览器跟随电脑的系统网络设置，浏览网页与 API 连接的代理设置分别处理。
- 改善网页加载、用户接管和验证页面提示；遇到网站验证时，由用户完成验证后继续任务。
- 修复输入内容较多时，思考强度等浮层偏离按钮的位置问题。
- 修复部分开发环境下意外退出的问题，并完善关闭时的资源清理。

## 问题反馈更方便

- 完善诊断包中的请求、工具调用和阶段计时记录，方便区分模型等待、资料读取与界面显示耗时。
- 修复部分诊断记录截断、中文文件名和计时口径问题，提高问题排查的准确性。

本版请使用完整安装包升级。安装前请先完成或停止正在运行的任务。
