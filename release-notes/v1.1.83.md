# Zen AI v1.1.83 更新说明

本次为新版智能助手加入运行中追加消息的能力，并改善浏览器访问、文献检索和长任务的使用体验。

## 任务进行中，也能继续提要求

- 助手运行任务时，输入框仍可使用，不必等当前任务结束才能发送下一条消息。
- 默认使用「排队发送」：等当前任务完成后，按顺序处理后续消息。
- 点击发送按钮旁的菜单，选择「调整当前任务」，可以补充条件、纠正方向；助手会在后续处理步骤中读取新要求。
- 输入框上方可以查看待发送消息，并支持编辑、移除、暂停和继续队列。切换会话或页面后，内容仍会保留。
- 停止任务或执行出错时，后续队列会暂停；重启软件后也需要手动继续，避免在不知情的情况下重复执行。
- 补充要求的接收与处理状态会单独显示。遇到结果尚未确认的情况，可以先核对对话记录，再决定是否继续发送。

## 浏览器使用电脑本身的网络

- 助手浏览器跟随电脑的系统网络设置。电脑开启系统代理时，助手浏览器也可以使用；模型 API 连接仍遵循软件中的代理设置。
- 改善部分网站对浏览器环境的识别，减少兼容性问题。
- 遇到需要登录或人工验证的页面，可以接管浏览器操作，完成后再继续任务。接管期间会暂停自动操作，避免与人工操作冲突。
- 对内置浏览器中难以完成的验证，提供使用系统浏览器打开的入口，方便继续访问网站。

## 改善文献检索和长任务体验

- 减少首次使用搜索工具时不必要的准备等待。
- 改善文献检索、复杂任务和较长工具调用的超时判断，让仍在持续处理的任务有机会正常完成。
- 等待用户授权或接管浏览器时，采用更合理的等待机制。
- 完善任务诊断和耗时说明，方便区分网络等待、模型输出与工具处理所花费的时间。

本版请使用完整安装包升级。安装前请先完成或停止正在运行的任务。
