# Zen AI 1.1.76

## 智能助手

- OpenCode 内核升级至 1.19.4，配套插件、SDK 和离线运行依赖同步更新。
- 新对话输入内容后保留草稿；切换对话或页面再返回时恢复浏览位置。
- 完善文件成果入口和路径检查，减少临时文件、重复文件或已经不存在的文件出现在交付列表中。
- 修复 PDF 分页与中文字体问题，支持按指定页数生成，并在保存前检查实际页数。
- 完善任务中断、错误诊断与权限提示，保留 OpenCode 原生执行和上下文管理机制。

## 技能与内容质量

- 中文写作按需引入 Humanizer-zh 润色参考，保留已有平台模板，并强调事实、数字、语气与确定程度的保留。
- 学术研究加入引文检查与来源元数据提取；论文写作加入离线数字及方法、结果一致性检查。
- 办公文件强化页数、工作表、公式、最终结论和实际文件路径验收。
- 修复同一软件版本内技能内容更新不能同步的问题；覆盖本地修改前保留备份，保留技能启用状态。
- 技能维护评测改用 OpenCode，超时和接口错误单独计为错误；普通用户任务不会自动运行额外评测。

## 图片工作台

- 精简图片入口和工作台交互，改善参考图、图片尺寸、生成记录和任务诊断展示。
- 优化图片请求与本地资源处理，便于定位上传、中转和上游生成各阶段的耗时。

## 升级提示

- 本版使用完整安装包升级。关闭软件后安装新版，再重新启动。
- 学术引用工具所需依赖随受管 Python 运行包更新，首次使用可能需要准备运行环境。
- 本版包含后续热更新能力的基础代码，生产热更新保持关闭，仍通过完整安装包交付。
- 实际任务耗时取决于模型、渠道、网络和任务内容；内核升级与技能检查通过不代表所有任务都会提速。
